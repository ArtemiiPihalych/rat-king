# Крысиный король

2D-прототип головоломки для браузера, планшета и телефона.

**[Играть в браузере](https://artemiipihalych.github.io/rat-king/)** · [Исходный код](https://github.com/ArtemiiPihalych/rat-king)

## Публикация

GitHub Actions проверяет генератор, собирает игру и публикует `dist/` на GitHub Pages после изменений в ветке `main`. Процесс описан в `.github/workflows/pages.yml`. В настройках Pages выбран источник GitHub Actions.

Пути к изображениям, звукам и файлам учитывают адрес проекта `/rat-king/`. Локальная разработка продолжает работать по корневому адресу.

## Запуск

Откройте `Start-Game.cmd` или выполните в этой папке:

```sh
npm run dev
```

Игра: http://localhost:5173/. Для проверки на iPad/Android в той же Wi-Fi-сети откройте Network-адрес, который выводит сервер. Компьютер с сервером должен оставаться включённым.

На этом компьютере зависимости установлены. Дополнительный Node.js 22.22.0 лежит в `.runtime/`; системный Node.js не изменялся. Скрипты автоматически используют локальную версию. На новом компьютере установите актуальный Node.js LTS, затем `npm install`.

## Что работает

- Собственные мультяшные крысы сверху, программная отрисовка хвостов и пересечений.
- Процедурные уровни трёх сложностей: 5, 8 или 11 крыс. У каждого хвоста 5–6 перегибов уже на начальной сложности.
- Нажатие освобождает крысу, если её хвост нигде не прижат оставшимся хвостом.
- Нажатие на заблокированную крысу показывает причину; жизни и таймер отсутствуют.
- Удержание выделяет хвост. Мышь также выделяет хвост при наведении.
- Бесплатные подсказки, отмена, перезапуск, новые клубки.
- Общий клубок дня (смена даты по Asia/Yekaterinburg), коды для повторного открытия уровня.
- Сохранение текущих ходов и статистики в localStorage на устройстве.
- Звук по желанию, режим уменьшенного движения, клавиатурные и экранные средства доступности.

Цифры 1–9 выбирают соответствующую крысу; H вызывает подсказку. Все крысы доступны через клавиатурные кнопки, появляющиеся при фокусе, включая № 10 и 11.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview
```

Тесты проверяют 1 000 комбинаций кодов и сложностей: решаемость, произвольный допустимый порядок ходов, участие всех крыс в переплетении, расстояния между пересечениями, соответствие геометрии правилам, воспроизводимость и отсутствие одинаковых отпечатков в выборке. Это не доказательство глобальной уникальности бесконечного множества уровней.

Готовая веб-сборка находится в `dist/`.

## Устройство

- `src/generator.ts` — генератор, геометрия, зависимости, решатель, коды.
- `src/woven-paths.ts` — прокладка извилистых хвостов и контроль допустимых пересечений.
- `src/scene.ts` — Phaser 3, игровое поле, касания и анимации.
- `src/rat-art.ts` — оригинальные программно нарисованные персонажи.
- `src/main.ts` — меню, состояние партии, подсказки, статистика.
- `src/storage.ts` — проверка и сохранение состояния.
- `tests/generator.test.ts` — проверки генерации и правил.
- `docs/GENERATION.md` — алгоритм и ограничения.
- `docs/ASSET-SOURCES.md` — найденные ассеты и условия лицензий.

## Границы первой версии

Это локальный прототип, ещё не приложение для магазинов. Мобильные оболочки Capacitor, реклама, облачная синхронизация и установка PWA не подключены. После загрузки игра генерирует новые уровни без сервера, но повторное открытие страницы пока требует доступного сервера.

Текущий генератор строит извилистые маршруты по общей невидимой сетке: у каждого хвоста 5–6 поворотов. Различаются геометрия, блокировки, цвета и порядок освобождения. Следующий этап — расширение семейств клубков и игровая оценка сложности. Допустимые ходы безопасны: освобождение никогда не создаёт новую блокировку.

Новые уровни используют формат RK2. Старые RK1-коды продолжают открывать исходные уровни с одним перегибом. При следующих изменениях алгоритма нужно сохранять воспроизводимость кодов предыдущих версий.

## Графика и лицензии

Персонажи, логотип, оформление и генератор созданы для этого проекта. Используются два коротких звука Kenney UI Pack, CC0; лицензия сохранена рядом с файлами. Другие найденные крысы, наборы и чужой код игры в сборку не включены. Исследовательские материалы находятся в `research-assets/` и не входят в production-сборку.
